# 💼 Sistema de RH em Python

Este programa simula o cadastro, exclusão e visualização de empregados cadastros NO sistema de RH de uma empresa. O arquivo `empregados.json` atua como um banco de dados tabela única.

## 📚 Conceitos praticados

- **Conceitos de JSON e Python:** Transformação de Object para Dictionary ou String, Null para None, etc.
- **Context Managers:** Uso de `with open()` junto com os argumentos `r` e `w` para ler e alterar o arquivo JSON.
- **Comandos Básicos:** `json.load()` e `json.dump()`.

## 🚀 Como executar

1. Certifique-se de ter o Python instalado.
2. Clone este repositório:
   ```bash
   git clone https://github.com/Davi-SantosOlv/rh-json-python.git
   ```
3. Entre na pasta do projeto e execute:
   ```bash
   python main.py
   ```

## 🎯 Objetivo

Conhecer o JSON Module para Python e praticar a leitura e escrita de dados neste tipo de arquivo
